# cacapalavras

Jogo casual de adivinhação de palavras em português brasileiro.

## Abrir

Abra [`index.html`](index.html) no navegador para iniciar o jogo. Se o redirecionamento local não funcionar, abra [`prototypes/visual.html`](prototypes/visual.html) diretamente.

O jogo inclui um desafio diário determinístico, treino em três níveis, teclado físico e virtual, validação de vocabulário demonstrativo, progresso e estatísticas salvos localmente, e compartilhamento sem spoiler. O calendário de palavras e o vocabulário são demonstrativos; os dados ficam neste navegador, sem conta, servidor ou sincronização entre dispositivos.
